# 💚 Per Your Health

## 📌 Description (200 Words)
**Per Your Health** is a modern and user-friendly health expense tracking application designed to help users manage their medical and wellness-related expenses efficiently. In today’s fast-paced world, healthcare costs are increasing rapidly, making it essential to maintain proper financial tracking. This application provides a simple yet powerful interface where users can add, view, and organize their health-related expenses such as doctor visits, medicines, laboratory tests, and treatment costs.

The system is built using React.js and follows a modular component-based architecture, ensuring scalability and easy maintenance. Each feature is divided into reusable components such as ExpenseForm, ExpenseList, Header, and Receipt modules. This structure helps developers easily extend functionality in the future.

Per Your Health focuses on simplicity, performance, and clarity. It allows users to quickly input data and visualize their spending without complexity. The goal is to give users better financial awareness of their health journey.

This project is ideal for beginners learning React as well as developers who want to explore real-world health tech applications. It demonstrates best practices in UI development, component structuring, and state handling in React.
